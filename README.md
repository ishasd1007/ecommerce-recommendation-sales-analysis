# ecommerce-recommendation-sales-analysis
# E-commerce Recommendation & Sales Analysis

## Project Overview
This project analyzes e-commerce transaction data to understand sales performance, customer purchasing behavior, repeat purchases, and product associations. It uses Python, Excel, and Power BI to generate business insights and identify cross-selling opportunities.

## Business Problem
E-commerce businesses often struggle to understand why customers do not make repeat purchases and which products are frequently purchased together. This project analyzes transaction data to uncover purchasing patterns and support data-driven business decisions.

## Tools & Technologies
- **Python:** Data cleaning, exploratory data analysis, customer analysis, and market basket analysis
- **Excel:** Data inspection and analysis
- **Power BI:** Interactive sales and customer analytics dashboard
- **FP-Growth:** Frequent itemset mining for product association analysis

## Key Features
- Sales revenue and order analysis
- Monthly revenue trend analysis
- Best-selling product analysis
- One-time vs. repeat customer analysis
- Repeat purchase rate calculation
- Market basket analysis
- Product affinity and cross-selling recommendations

## Dataset
The project uses the Online Retail dataset containing transaction-level retail data.

The complete cleaned dataset is not included in this repository because of file-size limitations. The Power BI dashboard and analysis were developed using the cleaned transaction data.

## Project Files
- `cleaned_sales_data.csv` — Cleaned transaction data (not included in the repository)
- `monthly_sales.csv` — Monthly sales summary
- `customer_retention.csv` — Customer purchase frequency analysis
- `cross_selling_recommendations.csv` — Product association and recommendation results
- `.pbix` file — Power BI dashboard
- Python notebook — Data cleaning, analysis, and recommendation workflow

## Business Insights
The analysis helps identify sales trends, customer purchasing patterns, repeat customers, popular products, and potential cross-selling opportunities.

## Disclaimer
Product associations indicate potential cross-selling opportunities. They do not independently prove that recommendations increase repeat purchases or revenue.
